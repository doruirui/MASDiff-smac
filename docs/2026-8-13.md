# 2026-8-13 框架流程

读取 target  
读取初始数据集 D_r  
记录 round = -1 的初始最优 rho

```text
for round in rounds:

    Phase 1: Training Models

        1. 用 D_r 训练扩散先验
           无条件模式：p_theta(R)

           有条件模式：p_theta(R | Tau)

           含义：
               扩散先验学习已有数据中 R 的分布。
               有条件时，模型学习在不同 Tau 条件下应该生成什么样的 R。

        2. 用 D_r 训练 surrogate ensemble

           无条件模式：surrogate(R) ≈ rho

           有条件模式：surrogate(Tau, R) ≈ rho

           输出：
               mu_phi(Tau, R)
               sigma_phi(Tau, R)

           含义：
               代理模型用于快速预测候选 R 的 rho。
               mu_phi 表示预测均值。
               sigma_phi 表示不确定性。

    Phase 2: Sampling Candidates

        3. 定义 acquisition

           r_phi(Tau, R) =mu_phi(Tau, R) + gamma * sigma_phi(Tau, R)

           含义：
               mu_phi 高，说明模型认为该 R 可能效果好。
               sigma_phi 高，说明模型不确定，值得探索。
               gamma 控制探索强度。

        4. 定义目标后验 p_tar

           无条件模式：
               p_tar(R) ∝ p_theta(R) * exp(beta * r_phi(R))

           有条件模式：
               p_tar(R | Tau) ∝ p_theta(R | Tau) * exp(beta * r_phi(Tau, R))

           含义：
               p_theta 保证 R 不偏离已有合理奖励分布。
               exp(beta * r_phi) 让采样向高 rho 区域偏移。
               beta 控制向高分区域移动的强度。

        5. 用 RTB fine-tune 后验采样器 p_psi

           无条件模式：p_psi(R) ≈ p_tar(R)

           有条件模式：p_psi(R | Tau) ≈ p_tar(R | Tau)

           含义：
               p_psi 是真正用于生成候选 R 的后验采样器。
               RTB 的作用是让 p_psi 逼近目标后验 p_tar，
               从而更容易生成高 rho 的候选奖励。

        6. 采样 Tau_batch

           无条件模式：Tau_batch = [None, None, ...]

           有条件模式：Tau_batch = [Tau_1, Tau_2, ...]

           含义：
               无条件时不需要 Tau。
               有条件时，Tau 来自当前任务场景或数据集中已有条件信息。

        7. 从 p_psi 采样候选奖励 R

           无条件模式：R_candidate ~ p_psi(R)

           有条件模式：R_candidate ~ p_psi(R | Tau_batch)

           得到：CandidateSet ={(Tau_j, R_j)}

           含义：
               这里得到的是一批候选奖励矩阵。
               当前 SUMO 场景下，每个 R_j 是一个完整奖励矩阵。

        8. 使用 SHADE 进化优化候选奖励 R

           8.1 初始化进化种群 Population

               从当前采样得到的候选奖励集合中初始化种群。

               当前场景：
                   R.shape = [1557, 114]
                   dim = 177498
                   lb = 0.0
                   ub = 5.0
                   pop_size = 100

               含义：
                   每个个体都是一个完整奖励矩阵 R。
                   种群用于在候选空间内进一步搜索更高 fitness 的奖励。

           8.2 外部计算 fitness

               无条件：fitness(R) = posterior_score(R)

               有条件：fitness(Tau, R) = posterior_score(Tau, R)

               含义：
                   fitness 用于衡量当前候选 R 的好坏，
                   由扩散先验、代理模型和 posterior 评分共同决定。

           8.3 初始化自适应参数

               初始化：
                   M_F = 0.5
                   M_CR = 0.5
                
                含义：    
                    F 是变异强度，决定每次改动 R 的幅度。
                    CR 是交叉概率，决定新候选 R 有多少维度会采用变异后的值。

               同时维护：
                   S_F      : 成功个体对应的 F
                   S_CR     : 成功个体对应的 CR
                   archive  : 被淘汰个体组成的档案

           8.4 对每个个体采样 F 和 CR

               对种群中的每个个体 R_i：
                   F_i  = randn() * 0.1 + M_F
                   CR_i = randn() * 0.1 + M_CR

               并裁剪到：F_i, CR_i ∈ [0, 1]

           8.5 current-to-pbest/1 变异

               先按当前 fitness 排序，取 top 10% 个体作为 pbest 候选。

               对每个个体 R_i：
                   选择 R_pbest
                   从种群或 archive 中选择 R_r1、R_r2

               生成变异向量：V_i = R_i + F_i * (R_pbest - R_i) + F_i * (R_r1 - R_r2)
                
                含义：让候选 R 一边向当前更好的奖励矩阵靠近，一边保留随机探索能力。
           8.6 二项交叉

               对每个维度 d：
                   if rand < CR_i:
                       U_i[d] = V_i[d]
                   else:
                       U_i[d] = R_i[d]

               同时强制至少一个维度来自 V_i。

               边界处理：
                   U_i = clip(U_i, lb, ub)

           8.7 贪婪选择

               如果：
                   fitness(U_i) > fitness(R_i)

               则：
                   用 U_i 替换 R_i

               同时：
                   - 记录成功参数 F_i、CR_i
                   - 将被替换的旧个体加入 archive

           8.8 更新自适应参数历史

               根据成功样本更新：
                   M_F
                   M_CR

               含义：
                   后续个体的 F 和 CR 会逐渐偏向更有效的取值范围。

           8.9 精英保留

               找到当前最优个体 R_best，
               将最差的一部分个体替换为 R_best。

               作用：
                   防止最优解丢失，加快收敛。

           8.10 多样性维护

               当种群 fitness 方差过小，说明可能过早收敛。

               此时在 R_best 附近注入少量扰动个体：
                   R_inject = clip(R_best + noise, lb, ub)

               作用：
                   保持搜索多样性，继续探索更优候选。

           8.11 输出进化后的候选集合

               从当前种群中选出 fitness 最高的若干个体，
               作为下一步真实评估的候选奖励集合。

               CandidateSet_evolved = top_by_fitness(Population, L)

        9. filtering top-B

           按 posterior_score / acquisition 从 CandidateSet_evolved 中选择 B 个候选：

               SelectedSet = top_by_score(CandidateSet_evolved, B)

    Phase 3: Query Black-box    

        10. 调用 SumoBlackBoxEvaluator
    
            对每个候选 R：

                R
                -> 直接作用于 SUMO 环境或仿真参数
                -> 启动 SUMO 仿真
                -> 每个时间步采集宏观状态
                -> 得到 X = [X_1, X_2, ..., X_T]
                -> 根据目标计算 rho

            返回：
                Sample(
                    tau=Tau_or_None,
                    design=R,
                    observation=X,
                    objective=rho,
                )

        11. 得到新 batch data

            batch data =
                {
                    (Tau_new, R_new, X_new, rho_new)
                }

        12. 更新数据集 D_r

            D_r = D_r ∪ batch data

            可选：
                如果超过 buffer_size，
                保留 rho 高的样本或按 selector 规则裁剪。

        13. 记录当前最优结果

            best_sample = argmax rho(sample in D_r)

            记录：
                round
                best_rho
                dataset_size
                best_R
                best_X

循环结束后输出最终最优样本：
    R_best
    X_best
    rho_best
```
