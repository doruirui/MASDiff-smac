# 2026-8-2 SUMO 场景流程

## 1. 两种配置

当前框架设置两种模式：

```text
无条件模式：
    tau = None
    tau_dim = 0

有条件模式：
    tau = SUMO 状态向量
    tau_dim > 0
```

## 2. 数据格式

```python
Sample(
    tau=Tau_or_None,
    design=R,
    observation=X,
    objective=rho,
)
```

## 3. 新增 sumo.py

```text
1. 读取目标宏观状态 X* 和 SUMO 环境配置
2. 读取初始数据 D_r
3. 设置真实黑盒 f(R) 或 f(Tau, R)
```
SumoBlackBoxEvaluator黑盒：

输入：

```text
candidate = (Tau, R)
```

执行流程：

```text
1. 根据 target 读取 SUMO 地图和 route
2. 如果有条件 Tau，则使用 Tau 对应的初始拥堵状态/场景配置
3. 用 R 训练或运行策略
4. 启动 SUMO 仿真
5. 每个时间步采集宏观状态
6. 得到 X = [X_1, X_2, ..., X_T]
7. 计算 objective = rho
8. 返回 Sample
```

返回样本：

```python
Sample(
    tau=candidate.tau,
    design=candidate.R,
    observation=X,
    objective=rho,
)
```

## 4. 框架流程

```text
读取 target
读取初始 D_r
记录 round = -1

for round in rounds:
    Phase 1: Training Models
        1. 用 D_r 训练扩散先验
           无条件: p_theta(R)
           有条件: p_theta(R | Tau)

        2. 用 D_r 训练 surrogate ensemble
           无条件: surrogate(R) ≈ rho
           有条件: surrogate(Tau, R) ≈ rho

           输出:
           mu_phi(Tau, R)
           sigma_phi(Tau, R)

    Phase 2: Sampling Candidates
        3. 定义 acquisition
           r_phi(Tau, R) = mu_phi(Tau, R) + gamma * sigma_phi(Tau, R)

        4. 定义目标后验
           无条件:
           p_tar(R) ∝ p_theta(R) * exp(beta * r_phi(R))

           有条件:
           p_tar(R | Tau) ∝ p_theta(R | Tau) * exp(beta * r_phi(Tau, R))

        5. 用 RTB fine-tune p_psi
           无条件:
           p_psi(R) ≈ p_tar(R)

           有条件:
           p_psi(R | Tau) ≈ p_tar(R | Tau)

        6. 采样 Tau_batch
           无条件:
           Tau_batch = [None, None, ...]

           有条件:
           Tau_batch = [Tau_1, Tau_2, ...]

        7. 采样候选奖励 R
           无条件:
           R_candidate ~ p_psi(R)

           有条件:
           R_candidate ~ p_psi(R | Tau_batch)

        8. posterior local search
           优化:
           log p_theta(R | Tau) + beta * r_phi(Tau, R)

        9. filtering top-B
           按 posterior_score / acquisition 选出最值得真实评价的 B 个 R

    Phase 3: Query Black-box
        10. 调用 SumoBlackBoxEvaluator
            对每个候选:
                在 SUMO 中使用 R 训练或运行策略
                仿真得到 X
                计算 rho

        11. 得到 batch data
            batch data = {(Tau_new, R_new, X_new, rho_new)}

        12. 更新数据集
            D_r = D_r ∪ batch data

        13. 记录当前最优
```
