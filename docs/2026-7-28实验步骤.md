# 2026-7-27 实验步骤

## 1. 准备初始数据 `D_r`

```text
D_r = {(Tau_i, R_i, X_i, distance_i, objective_i)}
```

## 2. 定义真实黑盒函数 `f(x)`

```text
f(R) = -distance(X(R), X*)
```

流程为：

```text
输入候选奖励 R
-> 用 R 训练策略
-> 仿真得到宏观状态 X(R)
-> 和目标 X* 比较
-> 得到 distance
-> objective = -distance
```

## 3. 初始化模型和参数

初始化：

```text
扩散先验模型 p_theta
代理模型 surrogate ensemble
后验采样器 p_psi
RTB 模块
样本池 D_r
候选筛选器
实验日志
```

设置超参数：

```text
rounds：优化轮数
B：每轮真实评价的候选数量
beta：后验向高分区域偏移的强度
gamma：探索强度
buffer_size：样本池最大容量
```

## 4. 第 -1 轮：记录初始表现

在进入循环前，先从初始数据 `D_r` 中找当前最优样本：

```text
best = argmax_y D_r
```

## 5. 每一轮开始训练扩散先验 `p_theta`

```text
p_theta(R | Tau)
```

## 6. 训练 surrogate ensemble

```text
surrogate(x) ≈ f(x)
```

输出：

```text
mu_phi(Tau, R)：预测均值
sigma_phi(Tau, R)：预测不确定性
```

## 7. 构造 acquisition

```text
r_phi(R | Tau) = mu_phi(R | Tau) + gamma * sigma_phi(R | Tau)
```

含义是：

```text
预测效果好 + 不确定性高
```

这样能平衡 exploitation 和 exploration。

## 8. 构造目标后验 `p_tar`

```text
p_tar(R | Tau) ∝ p_theta(R | Tau) * exp(beta * r_phi(Tau, R))
```

含义是：

```text
既要像已有数据里的合理 R
又要朝代理模型认为高分的区域移动
```

## 9. 用 RTB 微调后验采样器 `p_psi`

```text
p_psi(R | Tau) ≈ p_tar(R | Tau)
```

即用 RTB fine-tune 一个采样器，让它更容易生成高后验概率的候选。

## 10. 从 `p_psi` 采样候选

```text
R_candidate ~ p_psi(R | Tau)
```

用于生成很多候选奖励。

## 11. 候选局部搜索和筛选

对候选计算：

```text
posterior_score = log p_theta(R | Tau) + beta * r_phi(R | Tau)
```

然后进行：

```text
local search
top-B filtering
```

最终选出 `B` 个最值得真实评价的候选。

## 12. 查询真实黑盒 `f(x)`

对选出的每个候选执行真实评价：

```text
y_new = f(R_new)
```

流程为：

```text
R_new
-> 训练策略
-> 仿真
-> 得到 X_new
-> 计算 distance_new
-> objective_new = -distance_new
```

得到新 batch data：

```text
{(Tau_new, R_new, X_new, distance_new, objective_new)}
```

## 13. 更新数据集 `D_r`

```text
D_r = D_r ∪ batch data
```

并维护移动数据集大小。

## 14. 记录当前轮结果

记录每轮的：

```text
round
best_objective
best_distance
dataset_size
```
