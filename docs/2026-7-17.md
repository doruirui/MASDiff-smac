# 2026-7-17 新框架流程

## 0. 输入已有基线数据 Dataset_base

`Dataset_base` 中每个样本格式为：

```text
sample_i = (Tau_i, R_i, X_i, score_i)
```

其中：

- `Tau_i`：条件信息，用于扩散模型生成奖励
- `R_i`：基线奖励函数或奖励矩阵
- `X_i`：在 `R_i` 下训练策略并仿真得到的宏观状态序列
- `score_i`：该样本分数，越大越好

`score_i` 的定义：

```text
distance_i = Σ_{t=1}^{T} ||X_{i,t} - X*_t||
score_i = -distance_i
```

## 1. 读取或创建目标宏观状态序列 X*

```text
X* = [X*_1, X*_2, ..., X*_T]
```

## 2. 初始化各模块

```text
2.1 初始化扩散模型 diffusion_model
2.2 初始化代理模型 surrogate_model
2.3 初始化 RTB/后验引导模块 posterior_guidance
2.4 初始化环境 environment
2.5 初始化策略训练器 policy_trainer
2.6 初始化样本池 data_buffer
2.7 初始化选择器 selector
2.8 初始化评价指标 metric
```

## 3. 使用已有基线数据初始化样本池

```text
3.1 将 Dataset_base 加入 data_buffer

3.2 校验 Dataset_base 中每个样本是否包含：
    - Tau
    - R
    - X
    - score

3.3 可选：根据 X 和 X* 重新计算 score
    防止外部基线数据中的 score 与当前目标 X* 不一致
```

## 4. 预训练扩散模型和代理模型

```text
4.1 用 data_buffer 训练初始扩散模型
    训练目标：
    diffusion_model 学习 pθ(R | Tau)

4.2 用 data_buffer 训练初始代理模型
    训练目标：
    surrogate_model(Tau, R) ≈ score

4.3 可选：为 data_buffer 中样本设置训练权重
    例如：
    - score 越高，权重越大
    - Top 样本加权
    - 低分样本保留但降低权重
```

## 5. 主循环采样

```text
5. for k = 1 to K do：（主循环，共 K 轮）

   5.1 采样条件 Tau_batch
       5.1.1 从 data_buffer 中采样一批 Tau
       5.1.2 可选：混入目标条件 X*
       5.1.3 可选：优先采样高分样本对应的 Tau

   5.2 使用扩散模型生成候选奖励
       R_candidate ~ pθ(R | Tau_batch)

   5.3 使用代理模型预测候选奖励分数
       score_hat = surrogate_model(Tau_batch, R_candidate)

   5.4 使用代理模型 + RTB/后验进行引导采样
       后验目标：
       p_post(R | Tau) ∝ pθ(R | Tau) * exp(score_hat(Tau, R) / temperature)

       其中：
       pθ(R | Tau)：扩散模型当前学到的奖励先验
       score_hat(Tau, R)：代理模型预测的高分方向
       temperature：控制采样向高分区移动的强度

   5.5 得到引导后的候选奖励集合 CandidateSet
       CandidateSet = {
           (Tau_j, R_j, score_hat_j, posterior_weight_j)
       }

   5.6 可选：代理模型快速筛选
       从 CandidateSet 中选择代理预测分数最高的 Top-L：
       CandidateSet_selected = top_by_score_hat(CandidateSet, L)
```

## 6. 对候选奖励进行真实评估

```text
6. 对候选奖励进行真实评估

   for each (Tau_j, R_j) in CandidateSet_selected do：

       6.1 在 R_j 下训练每个智能体策略
           对每个智能体 k：
           π_{j,k} = argmax E[Σ_{t=1}^{T} γ^t r^t_{k,t}]

           其中：
           r^t_{k,t} = R_{j,k}(s_t, a_t)

       6.2 用训练好的多智能体策略 Π_j 进行仿真

       6.3 得到真实宏观状态序列 X_j
           X_j = [X_{j,1}, X_{j,2}, ..., X_{j,T}]

       6.4 计算真实距离
           distance_j = Σ_{t=1}^{T} ||X_{j,t} - X*_t||

       6.5 计算真实分数
           score_j = -distance_j

       6.6 保存真实评估样本
           evaluated_sample_j = (
               Tau_j,
               R_j,
               X_j,
               score_j,
               score_hat_j,
               posterior_weight_j
           )
```

## 7. 更新样本池

```text
7.1 从真实评估样本中选择 Top-B 个高分样本
    Top_new = selector.select_top(EvaluatedSet, B)

7.2 将 Top_new 加入旧样本池
    data_buffer = data_buffer ∪ Top_new

7.3 可选：控制 data_buffer 大小
    策略可以是：
    - 保留全部历史样本
    - 只保留 score 最高的 M_buffer 个样本
    - Top 样本 + 随机多样性样本
    - 按 score 设置采样权重
```

## 8. 更新扩散模型

```text
8.1 用更新后的 data_buffer 继续训练 diffusion_model

8.2 训练目标仍为：
    pθ(R | Tau)

8.3 可选：使用 score 加权训练
    高分样本权重大，低分样本权重小

8.4 更新后的扩散模型应逐渐偏向能产生高 score 的奖励区域
```

## 9. 更新代理模型

```text
9.1 用更新后的 data_buffer 继续训练 surrogate_model

9.2 训练目标：
    surrogate_model(Tau, R) ≈ true_score

9.3 可选：重点训练新加入的真实评估样本
    因为这些样本来自当前模型采样分布，更能修正代理模型偏差
```

## 10. 记录当前最优结果

```text
10.1 从 data_buffer 中选择全局最优样本
     best_sample = argmax score(sample)

10.2 记录：
     - 当前轮 k
     - best_score
     - best_distance
     - best_R
     - best_X
     - score_hat
     - true_score
     - data_buffer 大小

10.3 可选：保存 best_R、best_X、日志 CSV、可视化结果
```

## 11. 循环结束后输出最终结果

```text
11.1 输出最优奖励函数 R_best

11.2 输出 R_best 对应的策略 Π_best

11.3 输出最终宏观状态序列 X_best

11.4 输出目标宏观状态序列 X*

11.5 输出最终误差：
     final_distance = Σ_{t=1}^{T} ||X_best,t - X*_t||
```
