# 2026-6-16 采样方案

## 1. 总体流程

```text
1. 读取 100 个 Individual
2. 每个 Individual 提取 tau/reward 特征 z_i
3. 得到数据集 (z_i, rho_i)
4. 按 rho 分层做 5-fold cross validation
5. 每折划分 train / val / test
```

---

## 2. 读取 Individual

每个个体保留以下三部分：

```text
tau_i
reward_i
rho_i
```

暂时不使用：

```text
experience_buffers
policies
```

原因是这些字段体积较大，结构复杂，而且当前问题的核心是分析 `tau/reward` 与 `rho` 之间的关系。

因此每个样本可以表示为：

```text
Individual_i = (tau_i, reward_i, rho_i)
```

---

## 3. tau/reward 特征提取

原始 `tau` 和 `reward` 是高维矩阵。当前样本数只有 100 个，不适合直接使用完整矩阵训练大模型。

因此需要把每个个体压缩为一个特征向量：

```text
z_i = FeatureExtract(tau_i, reward_i)
```

### 3.1 reward 特征

可以从 `reward_i` 中提取以下统计量：

```text
reward_mean
reward_std
reward_min
reward_max
```

这些特征描述 reward 的整体分布。

### 3.2 tau 特征

```text
tau_mean
tau_std
tau_min
tau_max
```

这些特征用于描述交通状态本身的强度和变化。
---

## 4. 构造监督学习数据集

完成特征提取后，得到：

```text
D = {
  (z_1, rho_1),
  (z_2, rho_2),
  ...,
  (z_100, rho_100)
}
```

其中：

```text
z_i   是输入特征
rho_i 是监督标签
```

模型训练目标是：

```text
f_theta(z_i) ≈ rho_i
```

但实际任务不只是预测数值，还要能够筛选出更优的 reward。因此模型需要同时具备：

```text
1. rho 数值预测能力
2. reward 排序能力
3. 高 rho 个体筛选能力
```

---

## 5. 按 rho 分层做 5-fold Cross Validation

由于只有 100 个样本，如果只做一次随机划分，结果可能不稳定。

例如，随机划分可能导致：

```text
高 rho 样本大多进入训练集
低 rho 样本大多进入测试集
```

或者反过来，这都会影响评估结果。

因此建议按 `rho` 分层做 5 折交叉验证。

具体做法：

```text
1. 按 rho 从低到高排序 100 个样本
2. 按 rho 分布分成若干层
3. 从每一层中均匀抽样到 5 个 fold
4. 保证每个 fold 都包含低、中、高 rho 样本
```

最终得到 5 次实验：

```text
Fold 1: 80 个训练验证样本，20 个测试样本
Fold 2: 80 个训练验证样本，20 个测试样本
Fold 3: 80 个训练验证样本，20 个测试样本
Fold 4: 80 个训练验证样本，20 个测试样本
Fold 5: 80 个训练验证样本，20 个测试样本
```

每个样本都会恰好作为一次测试样本。

---

## 6. 每折 train / val / test 划分

每一折中，先固定：

```text
test = 20
train_val = 80
```

然后从 `train_val` 中继续划分：

```text
train = 64
val   = 16
test  = 20
```

三者作用不同：

```text
train: 用于训练模型，更新网络参数
val: 用于选择模型、调参和 early stopping
test: 用于最终评估泛化能力
```
